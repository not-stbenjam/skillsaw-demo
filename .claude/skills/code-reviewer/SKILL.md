# Code Review Skill

Review code changes for bugs, style issues, and potential problems.
Be thorough and be accurate in your analysis.

## What to Check

- Correctness and logic errors
- Security vulnerabilities
- Performance issues
- Code style and conventions
- Test coverage gaps

## Guidelines

Write clean code suggestions. Use common sense when prioritizing
issues. Follow best practices for the language in question.

When reviewing, appropriately categorize each finding by severity.
Correctly identify the root cause, not just symptoms.

Look at the diff in the pull request and compare against the repo
conventions. Check the related files in src/components for context.
Also review the types defined in src/types/index.ts.
