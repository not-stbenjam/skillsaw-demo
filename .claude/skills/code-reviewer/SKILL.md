# Code Review Skill

Review code changes for bugs, style issues, and potential problems.

## What to Check

- Correctness and logic errors
- Security vulnerabilities
- Performance issues
- Test coverage gaps

Run `git diff` to inspect changes. Check related files in
`src/components/` and `src/hooks/` for context.
